
LAN Messenger

Version History

--------------------------------------------------

1.3.0 ASHAI (10-10-2026)

  This is an unofficial fork of LAN Messenger prepared by ASHAI with the help of
  generative AI. It is a rebuild of the original application for a modern
  environment, including the changes made after the original release and listed
  below.

  Changes:
  - OpenSSL upgraded from 1.0.x to 4.0.1, backward compatibility preserved;
  - removed the startup SSL check (QT_NO_SSL / QSslSocket); LAN Messenger uses
    its own cryptography and the misleading warning dialog no longer appears;
  - message history moved to a SQLite database (messenger.db);
  - changed the history output format; file and folder transfers are now
    mentioned in the history;
  - changed the logic of the History button in conversations - history is now
    shown only for the current contact, and clearing deletes only the current
    contact's history;
  - added a search box to the History window;
  - the conversation window now remembers its size, the position of the divider
    between the conversation and the message input field, and the font across
    application restarts;
  - removed obsolete items from the Help menu;
  - added a new copyright line and the result of the authorship and integrity
    check of lmc.exe to the About dialog;
  - completed the interface translation - all strings that had remained
    untranslated have been translated;
  - the Windows installer now adds and removes the firewall exception through
    netsh advfirewall instead of the nsisFirewall plug-in;
  - added a portable mode - if a marker file named "portable" is present next to
    lmc.exe, all user data (settings, history, transfers, groups, avatar, cache,
    logs, themes and languages, downloads) is stored in a "data" subfolder next
    to lmc.exe, and the default paths are redirected there;
  - the application, the portable archive and the installer are now digitally
    signed; for external verification the public key is shipped as the file
    ".asc" and the signature as ".sig"; when the About window is opened,
    the presence of the files ".asc" and ".sig" next to lmc.exe, the match of
    the public key with the expected one, and the correctness of the signature
    are checked.

  Build environment:
  - Windows 11 24H2
  - Qt 5.12.12 built statically with MinGW 7.3.0 (32-bit),
  - Win32OpenSSL 4.0.1 (OpenSSL 4.0.1)
  - NSIS 3.12
  
  Source code: https://github.com/ashai-logic/lanmessenger
