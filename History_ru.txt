
LAN Messenger

История версий

--------------------------------------------------

1.3.0 ASHAI (10-10-2026)

  Это неофициальный форк LAN Messenger, подготовленный ASHAI с помощью генеративного
  ИИ. Это сборка исходного приложения для современного окружения, включающая изменения,
  внесённые после исходного выпуска и перечисленные ниже.

  Изменения:
  - OpenSSL обновлён с 1.0.x до 4.0.1, совместимость с предыдущими выпусками сохранена;
  - удалена проверка SSL при запуске (QT_NO_SSL / QSslSocket); LAN Messenger
    использует собственную криптографию, и вводящий в заблуждение диалог
    предупреждения больше не появляется;
  - история сообщений перенесена в базу данных SQLite (messenger.db);
  - изменён формат вывода истории, в истории теперь упоминаются передачи файлов и папок;
  - изменена логика работы кнопки истории в беседах - теперь история показывается
    только для текущего собеседника и при очистке удаляется история только текущего
    собеседника;
  - в окно истории добавлено поле поиска;
  - окно беседы теперь запоминает свой размер, положение разделителя между
    перепиской и полем ввода сообщения и шрифт при перезапуске приложения;
  - в меню Help убраны неактуальные пункты;
  - в меню About добавлен новый копирайт и результат проверки авторства и
    целостности lmc.exe;
  - завершён перевод интерфейса - переведены все строки, остававшиеся
    ранее непереведёнными;
  - установщик Windows теперь добавляет и удаляет исключение брандмауэра через
    netsh advfirewall вместо подключаемого модуля nsisFirewall;
  - добавлен портативный режим - если рядом с lmc.exe присутствует файл-маркер
    "portable", все пользовательские данные (настройки, история, передачи,
    группы, аватар, кэш, журналы, темы и языки, загрузки) сохраняются в
    подпапке "data" рядом с lmc.exe, и пути по умолчанию перенаправляются в неё;
  - приложение, портативный архив и установщик теперь имеют цифровую подпись;
    для внешней проверки публичный ключ поставляется в виде файла ".asc",
    подпись - ".sig"; при открытии окна About проверяется наличие файлов ".asc" и
    ".sig" рядом с lmc.exe, совпадение публичного ключа с ожидаемым и
    корректность подписи.

  Окружение сборки:
  - Windows 11 24H2
  - Qt 5.12.12, собранный статически с MinGW 7.3.0 (32-бит),
  - Win32OpenSSL 4.0.1 (OpenSSL 4.0.1)
  - NSIS 3.12

  Исходный код: https://github.com/ashai-logic/lanmessenger
